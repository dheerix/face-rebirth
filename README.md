# Face Rebirth

Face Rebirth is a structured repository for the brand, audience, marketing, sales, operations, and program materials behind the Face Rebirth project.

## Repository structure

- `docs/` — strategy, research, playbooks, and program documentation
- `website/` — landing page, blog, resources, and web assets
- `media/` — source media and creative files
- `templates/` — reusable project templates
- `roadmap/` — plans, milestones, and future work

## Current documentation

- Brand positioning: `docs/brand/`
- Audience profiles and strategy: `docs/audience/`
- Content and launch strategy: `docs/marketing/`
- Referral system: `docs/sales/`
- Daily operations: `docs/operations/`
- 21-day program structure: `docs/program/`
